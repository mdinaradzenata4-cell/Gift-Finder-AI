## პროექტის აღწერა
Gift Finder AI არის ხელოვნურ ინტელექტზე დაფუძნებული ასისტენტი, რომელიც მომხმარებელს ეხმარება საჩუქრის შერჩევაში. ის ითვალისწინებს ადრესატის ინტერესებს, ბიუჯეტსა და შემთხვევას. აგენტს შეუძლია პროდუქტების მოძიება გარე API-ის საშუალებით, საჩუქრების შენახვა სურვილების სიაში, შენახული საჩუქრების ჩვენება და წაშლა მომხმარებლის თანხმობის შემდეგ.

## ინსტალაცია

პროექტის გასაშვებად დააინსტალირეთ საჭირო ბიბლიოთეკები:

    pip install -r requirements.txt

## API გასაღების დამატება

შექმენით Groq API Key და დაამატეთ გარემოს ცვლადებში.

    GROQ_API_KEY=""

უსაფრთხოების მიზნით რეალური API გასაღები GitHub-ზე არ ატვირთოთ.

## პროექტის გაშვება

Terminal-ის ვერსია:

    python main.py

Streamlit-ის ვერსია:

    streamlit run app.py

## პროექტის ფაილები
- agent.py — აგენტის კოდი, ინსტრუმენტები და გრაფის კონფიგურაცია.
- app.py — მომხმარებლის ჩატის ინტერფეისი.
- main.py — Terminal-იდან გაშვების ვერსია.
- requirements.txt — საჭირო ბიბლიოთეკების ჩამონათვალი.
- README.md — პროექტის აღწერა და გაშვების ინსტრუქცია.
